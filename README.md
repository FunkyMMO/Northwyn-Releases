# Northwyn - game releases

This repository holds the published versions of the **Northwyn** game client. Players don't download anything here by hand: the Northwyn Launcher installs the game and keeps it up to date from these releases.

**Download the launcher:** [Northwyn-Launcher.exe](https://github.com/FunkyMMO/Northwyn-Releases/releases/latest/download/Northwyn-Launcher.exe) (Windows 10 or 11).

Each release is published from the Northwyn Server Console. Its files are content-addressed chunks (`<sha256>.chunk`) listed by `manifest.json`; later versions reuse chunks of earlier releases, so **never delete old releases**.
